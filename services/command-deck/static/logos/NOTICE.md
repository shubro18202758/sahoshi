# Agency and source marks

Agency and source marks belong to their owners. Sahoshi is a prototype and is not affiliated with or endorsed by them.

The marks below are used as-is: trimmed and resized only, never redrawn or recoloured. Most are not freely licensed (their own file pages say so); they stand for the agency or the data source they name, beside that name, and for nothing else. Where an agency has no mark on file (for example West Bengal Fire & Emergency Services, ERSS 112, the ambulance (108) service), Sahoshi shows its own generic badge instead.

- **kp** (Kolkata Police): public domain as stated on Wikimedia Commons (PD-textlogo, insignia; the Lion Capital PD-India); trademark/insignia of Kolkata Police. Source: https://commons.wikimedia.org/wiki/File:Kolkata_Police_Logo.png. Blue star badge with 'KOLKATA POLICE FORCE' round the national emblem, from the force's heraldry page (kolkatapolice.gov.in/heraldry). Also stands for Kolkata Traffic Police, which uses the same badge in gold. Dark blue artwork on transparent: needs a light plate on dark grounds. Contains the State Emblem of India, whose use is restricted by the State Emblem of India (Prohibition of Improper Use) Act, 2005. Changes: trimmed, resized to at most 128 px tall, metadata stripped.
- **wbp** (West Bengal Police): non-free logo (en.wikipedia; file page licence: Fair use). Source: https://en.wikipedia.org/wiki/File:West_Bengal_Police_Logo.svg. Red and navy shield with the national emblem, laurel, 'WBP' monogram and 'WEST BENGAL POLICE' (vector). The navy half would merge into a near-black ground, so it gets a light plate. Contains the State Emblem of India, whose use is restricted by the State Emblem of India (Prohibition of Improper Use) Act, 2005. Changes: kept as vector; scripts, metadata, comments and editor data stripped; viewBox ensured.

The source is an opaque 1430x1680 image whose white gaps between the letters run to the edges, so the white is part of the mark and was kept (no background removal); it reads as a solid tile on any ground. Changes: trimmed, resized to at most 128 px tall, metadata stripped; kept opaque.

A near-invisible soft glow at the bottom edge was trimmed off with the margin. Contains the State Emblem of India, whose use is restricted by the State Emblem of India (Prohibition of Improper Use) Act, 2005. Changes: trimmed, resized to at most 128 px tall, metadata stripped.
